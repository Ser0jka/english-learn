### Как появляется контекст

1. Сервер ищет выражение в локальном корпусе. Поддерживаются точная последовательность слов, основные формы первого глагола (`give/gave/given`, `fall/fell/fallen`, обычные `-ed/-ing`) и притяжательные местоимения вместо `one’s`. Совпадения внутри чужого слова, через границы предложений и абзацев не принимаются. Разделённые дополнением фразовые глаголы и все грамматические варианты этим поиском не покрываются.
2. Помощник получает настоящие отрывки с ID и значение изучаемого выражения. Для пакета передаются небольшие выборки из разных книг с ограничением размера запроса; полный корпус в модель не отправляется.
3. Модель выбирает только подходящие ID с высокой уверенностью. Другой смысл или сомнение дают пустой результат. Текст, автор, произведение и адрес берутся сервером из выбранного источника; присланные моделью альтернативные цитаты или атрибуции игнорируются.
4. Под отрывком показываются **краткое описание ситуации по-русски и объяснение значения**, помеченные как материал помощника. Это не полный перевод цитаты. При живой проверке полный автоматический перевод сложных абзацев оказался ненадёжным; для новых контекстов он заменён кратким разбором. Существующие редакционные переводы сохранены.

Для новых выражений `/api/materials/phrases` автоматически выполняет этот поиск после генерации. Для существующего выражения поиск запускается при раскрытии справки, если готового книжного контекста ещё нет и помощник подключён. `/api/materials/contexts` принимает до пяти выражений с переводами и определениями. Ошибка дополнительного запроса не удаляет уже полученные выражения: показывается возможность повторить поиск. Отсутствие подходящего отрывка относится только к этому корпусу, а не ко всем книгам мира.

У цитаты есть название, автор, год, раздел при наличии, номер абзаца и выделенное употребление. Нажатие на новый отрывок или «Читать полный текст в приложении» открывает книгу около нужного абзаца. Есть переход к началу, страницы по 30 абзацев, оригинальное издание и скачивание полного `.txt` с лицензией. Если нумерация изменилась, читатель ищет дословный отрывок; при его отсутствии открывает начало с объяснением. Текст выводится как обычный текст React, без вставки стороннего HTML.

Найденный контекст сохраняется в резервной копии и прогрессе браузера, отдельно для ID и значения выражения, до 500 записей. Новые поля обратно совместимы; небезопасные URL, пути вместо ID книг и некорректные номера абзацев отклоняются. Полные книги не записываются в `localStorage`.

### Обновление корпуса

```bash
npm run build:books
npm run build
```

Для обновления книг нужен Python 3 со стандартной библиотекой и сеть. При обычном `npm ci`, сборке и запуске Python не нужен: корпус уже включён в репозиторий. Скрипт использует `.book-corpus-cache/`, проверяет закреплённые контрольные суммы и завершается ошибкой при неожиданном изменении источника.

Ограничения: это десять исторических книг, без поиска по всему интернету, современным СМИ и платным книгам. Полного покрытия словаря нет. Точность цитаты проверяется по источнику; соответствие значения и русский разбор автоматические и могут требовать редакторской проверки. Настоящий iPhone/Safari не проверялся.

## Редакционная подборка — 16 октября 2026

В раскрываемой справке выражения литературный пример отделён от учебного и словарного. Карточка цитаты показывает вид текста, английский отрывок, русский перевод, автора, произведение, главу/сцену и пояснение ситуации. Сам отрывок и ссылка «Читать полный текст» открывают внешний источник в новой вкладке; пользовательский прогресс в приложении сохраняется. Чтение внешнего источника требует сети, доступность сторонних сайтов приложение не гарантирует. Книги Project Gutenberg открываются целиком, ссылки Folger — на цитируемую сцену пьесы с навигацией по произведению.

Редакционно проверенный литературный контекст подготовлен для **6 выражений**, включая три конкретных словарных значения. Это редакционно проверенная подборка, не автоматическое покрытие всех 5562 значений. У остальных выражений сохраняется доступный учебный/словарный пример; вымышленные цитаты не добавляются. Groq создаёт только явно обозначенные учебные примеры и не назначает им автора или источник.

## Проверка книжного корпуса — 17 октября 2026

Финальная версия прошла ESLint, TypeScript, production-сборку, **168 тестов Vitest** и **108 production-сценариев Chromium** без пропусков и повторов упавших тестов. Новые проверки охватывают контрольные суммы всех десяти книг и оригиналов, точность отрывков и атрибуций, формы слов, недопустимые ID/номера абзацев, выбор источников только по известным ID, отказ при другом значении/низкой уверенности, ограничение размера пакетного запроса, восстановление прогресса, чтение на 320/1440 px с axe, открытие нужного абзаца, страницы, скачивание оригинала, ошибку целостности с повтором загрузки и открытие книги после офлайн-перезагрузки.
