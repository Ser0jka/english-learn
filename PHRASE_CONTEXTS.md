# Контекст выражений и полный текст

В раскрываемой справке выражения литературный пример отделён от учебного и словарного. Карточка цитаты показывает вид текста, английский отрывок, русский перевод, автора, произведение, главу/сцену и пояснение ситуации. Сам отрывок и ссылка «Читать полный текст» открывают внешний источник в новой вкладке; пользовательский прогресс в приложении сохраняется. Чтение внешнего источника требует сети, доступность сторонних сайтов приложение не гарантирует. Книги Project Gutenberg открываются целиком, ссылки Folger — на цитируемую сцену пьесы с навигацией по произведению.

Сейчас литературный контекст есть у **6 выражений**, включая три конкретных словарных значения. Это редакционно проверенная подборка, не автоматическое покрытие всех 5562 значений. У остальных выражений сохраняется доступный учебный/словарный пример; вымышленные цитаты не добавляются. Groq создаёт только явно обозначенные учебные примеры и не назначает им автора или источник.

Новые четыре отрывка из Остин, Кэрролла и Конан Дойла 16 октября 2026 сверены целиком, с нормализацией только пробелов и переносов строк, с полными английскими текстами, полученными из зеркал GITenberg. Переводы и пояснения подготовлены для приложения; они не выдаются за опубликованные переводы книг. Исходные произведения находятся в общественном достоянии в США. Пользователю показываются ссылки на полные HTML-тексты Project Gutenberg. Свежая проверка доступности этих внешних HTML-страниц из облака была заблокирована сетевым прокси (403); браузерный тест проверяет открытие правильного URL с подменённым ответом внешнего сайта.

Метаданные `quote` обратно совместимы: прежние сохранения с `text`, `translation`, `author`, `url` читаются без новых полей. Поддерживаются также типы источника «статья» и «выступление»; готовых проверенных примеров этих типов пока нет. Новые поля проверяются при импорте резервной копии; небезопасные URL и неверные типы отклоняются. Источник не вставляется как HTML. Привязка словарных отрывков включает ID значения WordNet, поэтому разные значения одинаково написанной фразы не получают чужой контекст.

Проверки этого изменения: ESLint, TypeScript, 142 теста Vitest и production-сборка прошли. Все 65 production-сценариев Chromium прошли без повторных запусков или пропусков. Новые сценарии проверяют ссылки с клавиатуры и кликом на отрывок, открытие новой вкладки, доступность и отсутствие переполнения на 320 и 1440 px, сохранение выбранного выражения после перезагрузки и разделение значений. Метаданные проверены через полный экспорт/импорт резервной копии, включая старый формат и небезопасные ссылки. Мобильный блок также осмотрен по снимку из Chromium на ширине 390 px. Эти проверки не подтверждают доступность внешних сайтов или установку на VPS.
