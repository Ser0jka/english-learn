# Lexi — слова со смыслом

Приложение для русскоязычного ученика, который хочет расширять английский словарь через образы, выражения и чтение. Чёрная тема с латунными, серебряными и золотистыми акцентами, адаптивная версия для телефона.

## Запуск

Нужен Node.js 24 (или версия ≥ 22.9).

```sh
cd /workspace/english-learn
npm ci --cache /workspace/.npm-cache
npm run dev
```

Сервер слушает порт `5173` на `0.0.0.0`. Для другого порта задайте `PORT`. Проверка готовности: `curl -fsS http://127.0.0.1:5173/api/health`.

Для production:

```sh
npm run build
npm start
```

В облачной задаче используйте имеющийся checkout: задача уже изолирована, создавать дополнительный Git worktree не нужно.

На Mac также можно открыть `Start-Lexi.command`: он устанавливает зависимости при первом запуске, собирает приложение при необходимости и запускает сервер. Нужен Node.js 24; оставьте окно терминала открытым. Если приложение уже запущено, сначала остановите предыдущий процесс через `Ctrl+C`.

Личный архив с настроенным помощником содержит серверный `.env.local` и готовую сборку. Ключ сохраняется между перезапусками и не попадает в браузер. Такой архив предназначен только владельцу ключа: не публикуйте и не пересылайте его. Обычный архив GitHub по-прежнему не содержит секретов. При обновлении сохраняйте свой `.env.local` и экспортируйте прогресс браузера.

## Что работает без внешних сервисов

- Обзор коллекции, точность за 7 дней с числом ответов, разные значения за сегодня и настраиваемая цель (по умолчанию 10, можно отключить). Самооценка отделена от подтверждённых проверок.
- Подсказка первого запуска объясняет демонстрационную коллекцию и хранение прогресса; можно сразу открыть карточки или добавить своё слово.
- Личный словарь: добавление, поиск по слову/переводу, редактирование, удаление с подтверждением, статусы «Учу»/«Выучил».
- Импорт TXT, CSV, JSON (до 20 МБ, до 2000 слов за обычный импорт), предварительный разбор новых слов и дубликатов, перетаскивание файла. Полная резервная копия включает словарь, стабильные ID, статусы, расписание, историю ответов, интересы, сохранённые выражения, дополнительные тексты и свои изображения.
- 10 000 словарных карточек (7637 разных написаний) и 28 редакционных значений, 12 из которых уже в демонстрационной коллекции. Большая база загружается только при необходимости и не копируется целиком в прогресс. Материалы подставляются только при совпадении написания и значения; разные значения хранятся и повторяются отдельно. Остальные значения сохраняются без выдуманных переводов; их можно дополнить вручную.
- Карточки с локальными SVG-иллюстрациями, несколькими правильными словами/синонимами и переводами после ответа. Своя картинка: PNG/JPG/WebP до 650 КБ. Задания могут использовать картинку или пример со скрытым словом. Для неизвестного значения перед практикой нужно указать часть речи. Неготовые записи остаются в словаре. До ответа справка и озвучка ответа скрыты.
- После трёх верных самостоятельных ответов по сроку значение переходит в выученные; быстрые повторы не засчитываются. Ошибка возвращает его в изучение. Интервалы: 1, 3, 7, 14, 30, 60, 120, 180 дней; ошибка назначает короткий повтор через 5 минут. Режим повторения выбирает слова с наступившим сроком, включая изучаемые слова после ошибки или предыдущей практики. Режим изучения выдаёт новые и наступившие изучаемые значения, без будущих заданий. «Пора повторить» вычисляется по сроку и обновляется автоматически.
- Режим «Новые слова»: до 10 новых значений за сессию; в словарь попадают только отвеченные карточки. Приоритет выбранным темам, внутри словарной базы — порядок по частоте написаний в OpenSubtitles. Это не оценка уровня и не частота отдельных значений. Без картинки карточка честно использует английское определение со скрытым ответом.
- 12 редакционных выражений и 5562 словарных сочетания, в том числе 836 глагольных. Поиск, выдача порциями по 24, сохранение в изучаемые, озвучка, определения и источники. Для редакционной подборки есть употребление, нюансы, история и отдельные цитаты. У шести выражений есть литературный контекст: отрывок, перевод, автор, название, глава или сцена, пояснение ситуации и ссылка «Читать полный текст». Нажатие на сам отрывок тоже открывает источник в новой вкладке. Учебные, словарные примеры и цитаты подписаны отдельно. Из дополнительных сочетаний 522 имеют исходный английский пример; недостающие историю, регистр и перевод примера приложение не выдумывает. Это не корпус исключительно идиом и не подтверждённый частотный рейтинг выражений.
- Три оригинальных учебных текста, отсортированных по пересечению со словарём. Слова и выражения подсвечиваются, нажатие открывает перевод, весь текст можно перевести.
- Контекстная кнопка `?` со справкой из учебных материалов. За пределами справочника приложение честно сообщает об отсутствии ответа.
- Произношение средствами браузера, если поддерживается Web Speech API. Наличие английского голоса зависит от браузера и ОС.

Данные хранятся в `localStorage` текущего браузера, без аккаунтов и облачной синхронизации. При изменении словаря в другой вкладке устаревшая вкладка прекращает сохранение и показывает предупреждение: экспортируйте свои несохранённые изменения и перезагрузите страницу. Это защита от обычного конфликта вкладок, а не транзакционная база данных. Очистка данных сайта удаляет прогресс. Экспорт сохраняет коллекцию и прогресс целиком. При импорте резервной копии можно добавить только новые слова либо явно отметить восстановление всей коллекции с заменой текущих данных. История диалогов помощника хранится только до закрытия окна и в резервную копию не входит. Папка браузера пользователя не входит в файловый снимок среды.

## Подключаемые возможности ИИ

### Если после скачивания GitHub/ZIP кнопка ИИ недоступна

Секретный ключ не входит в репозиторий. Настройка облачной рабочей среды не переносится в скачанную копию. Создайте файл `.env.local` рядом с `package.json`:

```dotenv
LEXI_API_KEY=ваш_ключ_Groq
LEXI_API_BASE=https://api.groq.com/openai/v1
LEXI_MODEL=openai/gpt-oss-120b
```

Подставьте свой действующий ключ. Остановите запущенный сервер через `Ctrl+C` и запустите `npm run dev` или `npm start` заново: `.env.local` читается при запуске, перезагрузки страницы недостаточно. Затем нажмите «Попробовать снова» в окне ИИ. В Windows убедитесь, что файл называется именно `.env.local`, без окончания `.txt`.

Проверка: откройте `http://localhost:5173/api/health`. Поле `aiAvailable: true` подтверждает, что сервер прочитал ключ; успешный запрос генерации проверяет доступ к провайдеру. На хостинге те же переменные задаются в настройках серверного приложения, после чего его нужно перезапустить. При размещении только статических файлов (например, GitHub Pages) серверные ИИ-маршруты не работают: нужен запуск Node-сервера.

Никогда не добавляйте `.env.local` или настоящий ключ в Git, исходники интерфейса или публичный архив.

### Возможности и параметры

Для свободных вопросов, поиска дополнительных выражений, создания текстов из своей лексики и генерации иллюстраций нужен API с совместимыми с OpenAI интерфейсами. Это необязательная интеграция: без неё приложение работает на встроенных материалах.

Создайте `.env.local` по примеру `.env.example` и заполните `LEXI_API_KEY` через защищённые настройки среды или локальный секрет. Не добавляйте ключ в клиентский код и Git. В среде с ограниченным доступом к сети разрешите HTTPS к `api.groq.com`, `api.openai.com` или к хосту выбранного провайдера. Перезапустите сервер. `/api/health` сообщает только о наличии серверной настройки. Он не проверяет действительность ключа или ответ внешнего провайдера.

По умолчанию текстовая модель — `gpt-4o-mini`, модель картинок — `gpt-image-1`. Можно задать `LEXI_API_BASE`, `LEXI_MODEL`, отдельные `LEXI_IMAGE_API_BASE`, `LEXI_IMAGE_API_KEY`, `LEXI_IMAGE_MODEL`. Отдельный ключ `LEXI_IMAGE_API_KEY` позволяет включить только картинки, не включая свободный диалог. Нужны соответствующие права у провайдера. Генерация может тарифицироваться провайдером. Сервер разрешает только HTTPS-адреса провайдера, ограничивает размер запросов, время ожидания и число запросов.

| Переменная            | По умолчанию                | Назначение                                                             |
| --------------------- | --------------------------- | ---------------------------------------------------------------------- |
| `PORT`                | `5173`                      | HTTP-порт сервера, привязка к `0.0.0.0`                                |
| `LEXI_API_KEY`        | не задана                   | Серверный ключ для текста и, при отсутствии отдельного ключа, картинок |
| `LEXI_API_BASE`       | `https://api.openai.com/v1` | HTTPS API текстового провайдера                                        |
| `LEXI_MODEL`          | `gpt-4o-mini`               | Текстовая модель                                                       |
| `LEXI_IMAGE_API_KEY`  | `LEXI_API_KEY`              | Необязательный отдельный ключ картинок                                 |
| `LEXI_IMAGE_API_BASE` | `LEXI_API_BASE`             | HTTPS API генерации картинок                                           |
| `LEXI_IMAGE_MODEL`    | `gpt-image-1`               | Модель картинок                                                        |

При запросе помощнику передаются вопрос и выбранный учебный материал без картинки. Для подбора слов передаются тема, запрос и до 100 последних написаний для исключения повторов. Длинный контекст сокращается до лимитов сервера; полный текст вопроса сохраняется. Отправка происходит только при обращении к подключённой функции. Уточните правила хранения данных у своего провайдера.

Для Groq укажите `LEXI_API_BASE=https://api.groq.com/openai/v1` и доступную вашему аккаунту текстовую модель, например `LEXI_MODEL=openai/gpt-oss-120b`. Ключ остаётся в серверном `LEXI_API_KEY`. Этот пример модели не подтверждает её доступность для любого аккаунта. Groq используется для текста; его ключ не включает генерацию картинок. Для картинок нужны отдельные `LEXI_IMAGE_API_BASE` и `LEXI_IMAGE_API_KEY` совместимого провайдера.

Если облачная среда требует HTTP-прокси, Node.js 24 поддерживает `NODE_USE_ENV_PROXY=1`. Задайте её до запуска Node, например `NODE_USE_ENV_PROXY=1 npm start` или `NODE_USE_ENV_PROXY=1 npm run dev`: одной записи в `.env.local` для этого флага недостаточно. Для доверенного сертификата прокси задайте `NODE_EXTRA_CA_CERTS` с путём к его PEM-файлу. Не отключайте проверку TLS. Разрешение домена в черновике среды вступает в силу после сохранения/публикации настроек.

С ключом доступны:

- В «Новые слова» и «Мои слова»: **«Подобрать слова с ИИ»** — запрос своей темы, до 10 карточек, просмотр и выбор перед добавлением. Ответы не выдают сгенерированные уровни за CEFR; перевод и пример нужно проверить.
- В карточке слова в «Мои слова»: **«Создать иллюстрацию по слову»**. Перед сохранением можно проверить результат. Изображение уменьшается для локального хранения.
- В выражениях: **«Найти ещё выражения»** по введённому английскому слову. Подборка сохраняется на устройстве; повторные результаты пропускаются. Генератор не приписывает историю или цитаты источникам. Ссылка ведёт к поиску значения в Cambridge, а не утверждает, что результат был проверен словарём.
- В чтении: **«Создать текст»** с максимум 15 словами из выбранного режима. Текст честно обозначен как учебный текст помощника, а не как отрывок существующей книги.
- В `?`: свободные вопросы, на которые нет ответа во встроенной справке.

Фактическая проверка реального провайдера и ограничения сети описаны в [VALIDATION.md](VALIDATION.md). Контракт API, обработка ошибок, ограничение запросов и клиентские сценарии проверяются с тестовыми ответами. Перед публичным запуском с платным API добавьте аутентификацию пользователей, HTTPS и устойчивые ограничения запросов на уровне развёртывания. Текущий ограничитель — 12 запросов за минуту на IP в памяти одного процесса. Защита Origin и CSP не заменяет аутентификацию. Обратный прокси должен сохранять исходный заголовок `Host` для проверки Origin; доверенные прокси и корректный учёт IP настраиваются под конкретное размещение.

## Импорт

Одно слово на строку:

```text
forest
journey
```

CSV/TXT с разделителем `;`, `,` или табуляцией:

```csv
word;translation;status
forest;лес;learning
journey;путешествие;learned
```

Заголовки необязательны. Поддерживаются русские `слово;перевод;статус` и статусы `учу`/`выучил`. Для значений с разделителем используйте двойные кавычки. JSON принимает массив строк, массив объектов `{word, translation, status}` или экспорт приложения с массивом `words`. Для собственных материалов также поддерживаются `partOfSpeech`, `synonyms`, `definition`, `example`, `exampleRu`. Повторное написание с другим переводом — отдельное значение. Обычный список не переносит историю проверок; для точного переноса прогресса восстановите полную резервную копию.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm audit --audit-level=high
npm run test:e2e
E2E_PRODUCTION=1 E2E_PORT=5182 npm run test:e2e
```

`npm run typecheck` проверяет клиент, серверный JavaScript с JSDoc, конфигурации и тесты. Vitest проверяет импорт, интервалы, очередь повторения, синонимы, подсветку выражений, полное восстановление прогресса, повреждённые данные, нехватку памяти браузера и API. Playwright и axe проверяют пять экранов на ширинах 320, 390, 768 и 1440 px, контраст, формы и состояния ошибок. Playwright также проверяет пользовательские сценарии на Chromium, включая маршруты и историю браузера, мобильную навигацию и клавиатуру, полное восстановление прогресса, обработку ошибок и подключаемые возможности с тестовыми ответами. Тесты запускают свой сервер на порту 5180 (или `E2E_PORT`) с отключёнными реальными API-ключами; существующий dev-сервер не используется. `E2E_PRODUCTION=1` проверяет уже собранную production-версию.

Переменные только для тестов: `E2E_PORT` (5180), `E2E_PRODUCTION=1` (использовать production-сервер) и `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` (путь к Chromium). При наличии используется `/usr/bin/chromium`. На другой машине выполните `npx playwright install chromium` либо задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. `npm run format` форматирует исходники. `npm run check` запускает ESLint, типы, Vitest, сборку и браузерные тесты dev-режима; production-сценарии и аудит зависимостей выполняются отдельными командами выше. Workflow `.github/workflows/ci.yml` повторяет проверки для dev- и production-серверов в GitHub Actions после push или открытия PR. Добавление workflow не означает, что удалённый CI уже выполнялся.

- `src/data.ts` — встроенные материалы и источники.
- `src/components/WordArt.tsx` — локальные иллюстрации.

- `src/usePwa.ts`, `scripts/build-pwa.mjs` — установка, обновления и офлайн-сборка.
- `server.mjs`, `ai.mjs`, `http.mjs` — запуск, необязательный API помощника и HTTP-защита. Ключи остаются на сервере.

## Границы MVP

Приложение пригодно для личного использования; оно не является готовым многопользовательским сервисом. Кроме перечисленных ограничений ИИ и синхронизации:

- Валидатор принимает до 20 000 значений и 100 000 записей истории, но реальный объём ограничен квотой `localStorage` браузера. Особенно быстро её занимают картинки. Большие сохранения сжимаются автоматически; экспорт остаётся обычным JSON. Квота всё равно ограничивает изображения. Ошибка записи видна в интерфейсе; экспортируйте данные регулярно. Данные в браузере не шифруются приложением.
- Интервальное повторение использует фиксированную шкалу, а не индивидуальную модель памяти. Словарные соответствия извлечены из открытых данных, возможны ошибки источника; частота слов взята из субтитров, частотность редакционных выражений приблизительна. Свои значения и ответы генератора нужно проверять.
- UI проверен в Chromium, включая ширины 320–1440 px. Реальные телефоны, Safari/Firefox и экранные дикторы отдельно не проверены; автоматическая доступность не означает сертификацию WCAG.

Финальный технический аудит, исправления и фактически выполненные проверки: [TECHNICAL_AUDIT.md](TECHNICAL_AUDIT.md).

Большая словарная база: [WORD_BANK.md](WORD_BANK.md) — 10 000 карточек значений, источники, лицензии, алгоритм и ограничения.

## Телефон, оформление и офлайн

Развёртывание на личном VPS с Nginx, HTTPS, Groq и автозапуском: [deploy/README.md](deploy/README.md).

Приложение остаётся одной SPA с hash-маршрутами; нижняя панель телефона переключает пять разделов без перезагрузки. В «Мои предпочтения» доступны латунный, серебряный и золотисто-оранжевый акценты, два тёмных фона, увеличенный текст и зелёно-малиновый перелив ответов. Предпочтения входят в полную резервную копию.

Production-сборка включает manifest, иконки 192/512 px и service worker. Откройте HTTPS-адрес приложения: Android предлагает установку из меню браузера, iPhone — Safari → «Поделиться» → «На экран Домой». Для разработки также работает localhost. Dev-режим service worker не регистрирует.

Оболочка кешируется после первого открытия, большие базы — после открытия соответствующего раздела. Уже загруженные словари и локальный прогресс доступны без сети. Неоткрытая база требует подключения; ИИ всегда требует сети. Кеш не заменяет резервную копию: браузер может очистить его. Новая версия применяется по кнопке в настройках, с перезагрузкой после подтверждённого действия пользователя. Перед обновлением завершите редактирование и экспортируйте несохранённый прогресс при ошибке хранения.
