# Lexi — слова со смыслом

Приложение для русскоязычного ученика, который хочет расширять английский словарь через образы, выражения и чтение. Чёрная тема с латунными, серебряными и золотистыми акцентами, адаптивная версия для телефона.

## Запуск

Нужен Node.js 24 (или версия ≥ 22.9).

```sh
cd /workspace/english-learn
npm ci
npm run dev
```

Сервер слушает порт `5173` на `0.0.0.0`. Для другого порта задайте `PORT`. Проверка готовности: `curl -fsS http://127.0.0.1:5173/api/health`.

Для production:

```sh
npm run build
npm start
```

В облачной задаче используйте имеющийся checkout: задача уже изолирована, создавать дополнительный Git worktree не нужно.

## Что работает без внешних сервисов

- Обзор коллекции, реальная статистика ответов и ежедневная цель в 10 карточек.
- Личный словарь: добавление, поиск по слову/переводу, редактирование, удаление с подтверждением, статусы «Учу»/«Выучил».
- Импорт TXT, CSV, JSON (до 4 МБ, до 2000 слов), пропуск дубликатов, экспорт словаря в JSON, включая статусы, расписание и свои изображения.
- 24 слова в стартовой подборке, 12 из них уже в демонстрационной коллекции. Для известных слов автоматически подставляются перевод, пример, произношение и иллюстрация. Остальные слова сохраняются без выдуманных переводов; их можно дополнить вручную.
- Карточки с локальными SVG-иллюстрациями, несколькими правильными словами/синонимами и переводами после ответа. Своя картинка: PNG/JPG/WebP до 650 КБ. Слова без перевода или картинки остаются в словаре, но не попадают в визуальные задания.
- После трёх верных ответов подряд слово переходит в выученные. Ошибка возвращает его в изучение. Интервалы: 1, 3, 7, 14, 30 дней; ошибка назначает короткий повтор через 5 минут. Режим повторения выбирает выученные слова с наступившим сроком, режим изучения позволяет практиковать все изучаемые слова.
- Рекомендации новых слов из стартовой подборки, с приоритетом выбранных интересов. Это редакционная подборка, не персональная оценка уровня и не полный частотный корпус.
- 12 выражений: поиск, сохранение в изучаемые, употребление, нюансы, история, учебные примеры и отдельные литературные цитаты со ссылками. Частотность приблизительная, редакционная.
- Три оригинальных учебных текста, отсортированных по пересечению со словарём. Слова и выражения подсвечиваются, нажатие открывает перевод, весь текст можно перевести.
- Контекстная кнопка `?` со справкой из учебных материалов. За пределами справочника приложение честно сообщает об отсутствии ответа.
- Произношение средствами браузера, если поддерживается Web Speech API. Наличие английского голоса зависит от браузера и ОС.

Данные хранятся в `localStorage` текущего браузера, без аккаунтов и облачной синхронизации. Очистка данных сайта удаляет прогресс. Экспорт — перенос словаря, не полный архив статистики, дополнительных текстов и истории диалогов. Папка браузера пользователя не входит в файловый снимок среды.

## Подключаемые возможности ИИ

Для свободных вопросов, поиска дополнительных выражений, создания текстов из своей лексики и генерации иллюстраций нужен API с совместимыми с OpenAI интерфейсами. Это необязательная интеграция: без неё приложение работает на встроенных материалах.

Создайте `.env.local` по примеру `.env.example` и заполните `LEXI_API_KEY` через защищённые настройки среды или локальный секрет. Не добавляйте ключ в клиентский код и Git. Перезапустите сервер. `/api/health` возвращает только факт доступности, а не значение ключа.

По умолчанию текстовая модель — `gpt-4o-mini`, модель картинок — `gpt-image-1`. Можно задать `LEXI_API_BASE`, `LEXI_MODEL`, отдельные `LEXI_IMAGE_API_BASE`, `LEXI_IMAGE_API_KEY`, `LEXI_IMAGE_MODEL`. Нужны соответствующие права у провайдера. Генерация может тарифицироваться провайдером. Сервер разрешает только HTTPS-адреса провайдера, ограничивает размер запросов, время ожидания и число запросов.

С ключом доступны:

- В карточке слова в «Мои слова»: **«Создать иллюстрацию по слову»**. Перед сохранением можно проверить результат. Изображение уменьшается для локального хранения.
- В выражениях: **«Найти ещё выражения»** по введённому английскому слову. Подборка сохраняется на устройстве; повторные результаты пропускаются. Генератор не приписывает историю или цитаты источникам. Ссылка ведёт к поиску значения в Cambridge, а не утверждает, что результат был проверен словарём.
- В чтении: **«Создать текст»** с максимум 15 словами из выбранного режима. Текст честно обозначен как учебный текст помощника, а не как отрывок существующей книги.
- В `?`: свободные вопросы, на которые нет ответа во встроенной справке.

Подключение к реальному провайдеру не проверялось без рабочего ключа. Контракт API, обработка ошибок, ограничение запросов и клиентские сценарии проверяются с тестовыми ответами. Перед публичным запуском с платным API добавьте аутентификацию пользователей и устойчивые ограничения запросов на уровне развёртывания.

## Импорт

Одно слово на строку:

```text
forest
journey
```

CSV/TXT с разделителем `;`, `,` или табуляцией:

```csv
word;translation;status
forest;лес;learning
journey;путешествие;learned
```

Заголовки необязательны. Поддерживаются русские `слово;перевод;статус` и статусы `учу`/`выучил`. Для значений с разделителем используйте двойные кавычки. JSON принимает массив строк, массив объектов `{word, translation, status}` или экспорт приложения с массивом `words`.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

Vitest проверяет импорт, интервалы, очередь повторения, синонимы, подсветку выражений и API. Playwright проверяет пользовательские сценарии на Chromium, включая мобильную навигацию, сохранение словаря и подключаемые возможности с тестовыми ответами.

При наличии используется `/usr/bin/chromium`. На другой машине выполните `npx playwright install chromium` либо задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. `npm run format` форматирует исходники.

## Структура

- `src/App.tsx` — оболочка, обзор, словарь и настройки.
- `src/components/Study.tsx` — карточки, выражения, чтение.
- `src/domain.ts` — импорт, прогресс, сохранение и расписание.
- `src/data.ts` — встроенные материалы и источники.
- `src/components/WordArt.tsx` — локальные иллюстрации.
- `server.mjs`, `ai.mjs` — запуск и необязательный API помощника. Ключи остаются на сервере.

Шрифты Golos Text и Manrope поставляются локально через Fontsource (SIL OFL). Иллюстрации карточек созданы для приложения. Фотография гор взята из шаблона [Start Bootstrap Grayscale](https://github.com/StartBootstrap/startbootstrap-grayscale), лицензия шаблона сохранена в `public/images/PHOTO-LICENSE.txt`; [лицензия исходных фотографий Unsplash](https://unsplash.com/license). Учебные тексты и переводы созданы для приложения. Цитаты Шекспира сопровождаются ссылками на Folger Shakespeare Library.
