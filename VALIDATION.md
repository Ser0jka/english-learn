# Отчёт о проверке Lexi

Дата: 16 октября 2026. Node.js 24.19.0, npm 11.9.0, Chromium в Linux. Это продолжение технического, UX и образовательного аудитов: [TECHNICAL_AUDIT.md](TECHNICAL_AUDIT.md), [UX_AUDIT.md](UX_AUDIT.md), [LEARNING.md](LEARNING.md).

## Очистка интерфейса и личная сборка с Groq — 16 октября 2026

По запросу пользователя убраны технические инструкции из учебных экранов: ключи, `.env.local`, названия провайдеров и словарных баз, длинные объяснения генерации и служебные подписи. Успешное подключение не создаёт баннер. При недоступности остаются короткое сообщение и повтор запроса. Источники и лицензии доступны отдельной ссылкой в настройках; документация настройки остаётся в README. Сгенерированные выражения отмечены коротким «Подобрано ИИ». История и нюансы сохранены там, где есть учебное содержание; для словарной базы скрыты повторяющиеся сообщения об отсутствии сведений.

Добавлен `Start-Lexi.command` для локального запуска: установка зависимостей по lockfile при необходимости, сборка при её отсутствии и запуск сервера. Синтаксис проверен `bash -n`. Подготовлен отдельный личный архив с готовой сборкой и серверной настройкой. В нём секрет находится только в `.env.local`, не в исходниках или браузерных файлах. Сам архив хранится вне Git с правами 600 и не предназначен для публикации. Публичный GitHub/ZIP остаётся без ключа.

Фактически выполнено:

- ESLint и TypeScript — успешно; production-сборка — успешно.
- Vitest — 130 тестов в 10 файлах, без пропусков.
- Полный Chromium: 61 сценарий dev и 62 production, без пропусков и повторных попыток.
- В настоящем браузере на 390×844 через кнопку подбора Groq вернул 10 карточек по теме чувств; инструкции для разработчика отсутствуют, ошибок JavaScript не было.
- Личный архив распакован в отдельную закрытую временную папку. Из неё выполнены установка зависимостей, запуск через `Start-Lexi.command`, остановка и повторный запуск. Затем реальный Groq вернул HTTP 200 и 10 карточек; настройка сохранилась между процессами. Временная распаковка удалена.
- Публичные исходники и `dist` не содержат предоставленного ключа; запрос `/.env.local` не раскрывает его.

В тестах устранены две причины нестабильности: проверка срока повторения теперь использует сохранённый срок и остановленные часы; инъекция повреждённого словаря выполняется в отдельном сценарии без service worker. Настоящий офлайн-сценарий PWA по-прежнему использует service worker. При повторном полном прогоне проверки не отключались.

Пакетный запуск проверен в Linux/bash с Node.js 24. Физический Mac, поведение Gatekeeper и двойной щелчок в Finder не проверялись. Это локальная сборка: постоянно доступный публичный сервер не развёрнут. Пользователю по-прежнему нужен Node.js 24 и доступ к интернету для Groq.

## Предыдущее исправление настройки скачанной копии — 16 октября 2026

При скачивании GitHub/ZIP серверный `.env.local` не переносится. Сообщение об отключённом ИИ теперь прямо объясняет отсутствие ключа, содержит раскрываемую инструкцию для Groq и кнопку повторной проверки после настройки. Наличие серверной настройки больше не выдаётся за подтверждение ответа провайдера. Запрос состояния не использует кеш.

После этой правки успешно выполнены ESLint, TypeScript и production-сборка, а также три целевых сценария Chromium: отсутствие настройки → инструкция → повторная проверка без потери запроса; подбор слов с ошибкой и повтором; справка со сменой состояния подключения. Новый сценарий включает axe и ширину 320 px. Полный прогон ниже выполнен для `5dee0cb`; на том этапе после этой точечной правки полный набор заново не запускался.

## Реализовано в текущем цикле

- Мобильная SPA: пять разделов переключаются без загрузки нового документа, нижняя навигация показывает текущий раздел, меню управляет фокусом и закрывается Escape. Учтены безопасные отступы телефона и экранная клавиатура. Стартовая карточка на 390×844 показывает четыре ответа над нижней панелью; на узких экранах и с длинными материалами доступна прокрутка.
- Настройки оформления: глубокий чёрный или графитовый фон, латунь/серебро/золотисто-оранжевый акцент, увеличенный текст, зелёно-малиновый перелив обратной связи. Настройки сохраняются и входят в полную резервную копию.
- 10 000 карточек значений, 7637 разных написаний, плюс 28 редакционных значений. База WordNet + OMW/Wiktionary сопоставлена по значению; порядок использует частоту написаний OpenSubtitles. До 10 новых значений за сессию, добавление в личный словарь после ответа. Для большинства новых карточек используется английское определение со скрытым ответом, а не изображение.
- 5562 значения выражений и словосочетаний, 5364 разных написания, включая 836 глагольных значений; дополнительно 12 редакционных выражений. Поиск по всей базе, выдача порциями, раскрытие сведений, сохранение в изучаемые и практика. Английский пример есть у 522 записей большой базы; остальные примеры, историю и регистр приложение не выдумывает.
- Большие словари загружаются отдельно с контролем SHA-256. Для коллекции из 10 000 значений добавлены сжатие сохранения и выдача списка порциями. Старые сохранения в обычном JSON читаются, экспорт остаётся полным обычным JSON. Защита от повреждения, переполнения и конфликта вкладок сохранена.
- PWA: manifest, собственные иконки, подготовка офлайн-оболочки, кеш уже открытых баз, предложение установки при поддержке браузером, явное применение обновлений. API и личные данные не помещаются в service-worker-кеш.
- Серверная интеграция Groq: подбор до 10 слов с переводом, определением и примером, выражения, учебные тексты, свободные вопросы. Новые слова сначала показываются для выбора. Типографские дефисы и апострофы нормализуются в английском написании и контексте, чтобы проверка и скрытие ответа работали согласованно.

Источники, лицензии и алгоритмы воспроизводимой подготовки: [WORD_BANK.md](WORD_BANK.md). Большие базы являются словарными материалами, а не результатом индивидуального ИИ-подбора.

## Реальные запросы Groq

Предоставленный ключ хранится только на сервере в игнорируемом `.env.local`; его значение не входит в Git, клиентскую сборку или архив исходников. После первоначальной сетевой блокировки повторная проверка достигла провайдера. Авторизованный `GET /models` вернул HTTP 200. Первоначальная модель Llama уже отсутствовала в списке; выбрана доступная `openai/gpt-oss-120b`.

Через API работающего приложения, без подмены ответов, получены HTTP 200:

- `/api/materials/words`: 10 карточек по теме аэропорта и отеля;
- `/api/materials/phrases`: 5 выражений с `take`;
- `/api/materials/reading`: английский учебный текст с русским переводом по пяти переданным словам;
- `/api/assistant`: объяснение разницы `trip` и `journey`.

Эти проверки подтверждают работу текущей настройки и ключа в момент проверки. Они не гарантируют постоянную доступность модели, квоту или безошибочность учебного содержания. Автоматические тесты используют контролируемые ответы, не расходуя пользовательскую квоту.

В этой среде для Node понадобился `NODE_USE_ENV_PROXY=1` **до запуска процесса**, например `NODE_USE_ENV_PROXY=1 npm start`; одной записи флага в `.env.local` оказалось недостаточно. Используется доверенный сертификат прокси, проверка TLS не отключалась. Черновик облачной конфигурации содержит домен `api.groq.com` и новые инструкции запуска; сохранение черновика отдельно от его публикации в настройках среды.

## Ограничения MVP

- Это личное приложение: аккаунтов и автоматической синхронизации между устройствами нет. Прогресс остаётся в текущем браузере; резервные копии нужно экспортировать. Сжатие не является шифрованием и не отменяет квоту, особенно для картинок.
- Большая база не содержит 10 000 иллюстраций, подтверждённых уровней CEFR или полного набора историй/цитат. Она не состоит исключительно из идиом. Переводы и значения открытых источников могут содержать ошибки; ручной проверки каждой записи не было.
- Интервальное повторение использует фиксированные правила по ответам, а не индивидуальную модель памяти. Три успешные проверки по сроку дают отметку «Выучил»; ошибка возвращает в изучение. Распознавание по вариантам не доказывает свободное употребление.
- ИИ-материалы требуют проверки пользователем. Модель может выбирать неидеальный перевод, часть речи или длину текста. Генерация текста не выдаётся за цитату из существующей книги. В чтении пользователь выбирает значение многозначного слова.
- Groq в этой интеграции генерирует текст, но не картинки. Настоящая генерация изображений отдельным провайдером не выполнялась; её интерфейс, контракт и ошибки проверены с тестовыми ответами.
- Офлайн доступны только уже загруженные материалы. Установка PWA требует production и HTTPS либо localhost; физическая установка на iPhone/Android не проверялась. Реальные телефоны, Safari/Firefox, звучание системных голосов и экранные дикторы отдельно не проверены. axe не является сертификацией WCAG.
- Перед публичным многопользовательским размещением платного API нужны аутентификация и ограничения запросов на уровне развёртывания. Публичное размещение приложения не выполнялось.

## Запуск

```sh
npm ci
npm run dev
```

Порт по умолчанию `5173`. Production/PWA:

```sh
npm run build
npm start
```

При необходимости прокси запускайте с флагом, описанным выше. Настройка API и телефона: [README.md](README.md), [.env.example](.env.example). Для установки на телефон откройте HTTPS-адрес размещённого приложения и выберите «На главный экран» в браузере.
