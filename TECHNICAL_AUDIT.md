# Финальный технический аудит Lexi

Дата: 15 октября 2026. Проверялся весь репозиторий: клиент, доменная логика, Express API, тесты, зависимости и CI. Среда: Node.js 24.19.0, npm 11.9.0, Chromium в Linux.

## Оценка готовности

MVP рассчитан на личное использование: словарь, импорт и резервные копии, карточки, интервальное повторение, выражения, чтение и встроенная справка связаны и работают без внешнего API. Необязательный ИИ подключается серверными переменными. Публичный многопользовательский сервис требует отдельного этапа: аутентификации, HTTPS, устойчивых ограничений API и серверного хранения с синхронизацией.

## Ограничения проверки и сопровождения

- Реальный платный провайдер ИИ не проверен: рабочего ключа нет. Контракты API, ошибки и клиентская интеграция проверяются контролируемыми ответами.
- Браузерное покрытие — Chromium в Linux. Эмуляция размеров не заменяет реальные iOS/Android, Safari/Firefox, экранные дикторы и полную оценку WCAG.
- Хранилище — `localStorage`, с квотой браузера, без шифрования и синхронизации устройств. Защита вкладок предотвращает обычную перезапись устаревшего снимка, но не предоставляет транзакций базы данных. Нужны регулярные резервные копии.
- При публичном размещении защиты Origin/CSP недостаточно для платного API. Ограничитель в памяти одного процесса не рассчитан на несколько серверов и перезапуск. Прокси должен сохранять Host; доверенные прокси и IP настраиваются под размещение.
- ESLint 9 выбран по совместимости peer-зависимостей `eslint-plugin-jsx-a11y`. Установка предупреждает о завершении поддержки этой ветки; полный аудит npm уязвимостей не показывает. Переход на ESLint 10 следует выполнить после поддержки плагином, без принудительного нарушения peer-зависимостей.
- Проверки выполнялись локально в облачной среде. GitHub Actions подготовлен, но удалённый workflow не запускался. Аудит зависимостей отражает базу npm на дату проверки и не является полным пентестом.
