# Словарная база

Подготовлены **10 000 карточек значений, 7637 разных написаний**. Они дополняют 28 редакционных значений. Это словарные задания по английскому определению, иногда с исходным примером; иллюстрации не имитируются. Перевод и полный пример открываются после ответа. Режим «Новые слова» выдаёт до 10 значений за сессию; в личный словарь попадают только отвеченные карточки. Ошибка назначает повтор через 5 минут, успех — через сутки, далее действуют общие интервалы.

Источники и лицензии указаны в [публичном файле атрибуции](public/data/word-bank-credits.txt). Источники закреплены полными Git SHA и SHA-256 в [сборщике](scripts/build_word_bank.py); ключи и внешняя генерация не используются. Данные базы доступны в `public/data/word-bank.json` под CC BY-SA 4.0. Это компактный исходный формат базы, не файл резервной копии прогресса.

Алгоритм соединяет WordNet 3.0 и русские соответствия Wiktionary/OMW по synset ID. Из словарных значений выбираются общеупотребительные написания, не больше трёх значений одного написания, без одинаковых пар слово/перевод. Регистр и спорные словарные пометы фильтруются. Темы определяются по категориям WordNet. Частота взята из OpenSubtitles 2018: она относится к написанию, не к отдельному значению и не определяет CEFR. Неподтверждённые уровни, транскрипции и переводы примеров не добавляются.

Шесть потенциальных неправильных вариантов готовятся для каждой карточки детерминированно: та же часть речи, приоритет той же категории, без общих synset, русских эквивалентов и непосредственных словарных связей. На экране выбираются и перемешиваются варианты. Подсказка скрывает целевое слово и синонимы. Алгоритмические проверки всех карточек не заменяют поштучную редакторскую проверку: неточности исходного перевода и отдельные неоднозначные задания возможны.

Пересборка (Python 3, стандартная библиотека, сеть нужна только первый раз):

```sh
python3 scripts/build_word_bank.py --cache /tmp/lexi-word-bank-sources
```

Обычная установка приложения использует готовые файлы и не скачивает словари. Основные проверки: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`. Тест базы проверяет каждую из 10 000 карточек: валидность, дубликаты, целостность SHA-256, скрытие ответа и четыре разных варианта.

## Выражения

Дополнительно собраны 5562 значения устойчивых сочетаний (5364 разных написания): 836 глагольных, 175 наречных, 4516 сочетаний существительных, 35 сочетаний с прилагательным. Это все подходящие многословные записи закреплённого источника после фильтрации; не все они идиомы. 522 имеют исходный английский пример с данным сочетанием. Отсутствующие перевод примера, происхождение, стилистика и реальная частотность честно отмечаются как неподтверждённые. Подключённому ИИ можно задать вопрос об употреблении, но его ответ также требует проверки.

Пересборка: `python3 scripts/build_phrase_bank.py --cache /tmp/lexi-word-bank-sources`. Источники и лицензии те же; результаты — `public/data/phrase-bank.json` и `src/generated/phrase-bank-manifest.json`. Выражения выдаются порциями по 24. В личный словарь попадают только выбранные выражения; они получают ту же механику самостоятельной проверки и повторения.

Базы загружаются отдельными JSON с проверкой SRI/SHA-256; основной интерфейс не ждёт их загрузки. При ошибке есть повтор загрузки без изменения прогресса. Словарные идентификаторы сохраняются в резервных копиях, а неподтверждённый ID из импорта не делает произвольное определение готовым заданием.
