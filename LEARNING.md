# Правила обучения Lexi

Одна запись словаря — одно явно указанное значение. Написание и перевод определяют, является ли запись дубликатом. Для разных значений с одинаковым русским переводом добавляйте уточнение, например «ключ (музыкальный)». Расписание и история привязаны к стабильному ID записи.

## Что изменилось

Раньше три ответа подряд в одной сессии могли дать отметку «Выучил»: режим изучения игнорировал будущий срок. Кнопка справки раскрывала слово до ответа. Для любого знакомого написания подставлялись одни и те же материалы; отвлекающие варианты выбирались из произвольных слов. Теперь зачёт зависит от срока, материалы относятся к выбранному значению, а статистика отделяет практику от подтверждённого запоминания.

## Расписание

Это прозрачное расписание с фиксированными интервалами, зависящими от последовательности результатов. Это не FSRS, не оценка вероятности забывания и не модель индивидуальной памяти.

| Событие                                                | Результат                                                                               |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| Новое значение                                         | «Учу», первая самостоятельная проверка доступна сразу                                   |
| 1-й верный ответ по сроку                              | «Учу», следующая проверка через 24 часа                                                 |
| 2-й верный ответ по сроку                              | «Учу», следующая проверка через 3 суток                                                 |
| 3-й верный ответ по сроку                              | Базовая отметка «Выучил», следующая проверка через 7 суток                              |
| Дальнейшие верные ответы                               | 14, 30, 60, 120, затем 180 суток; 180 — верхняя граница                                 |
| Ошибка по сроку                                        | «Учу», последовательность успешных проверок обнуляется; повтор через 5 минут            |
| Верный ответ после ошибки                              | Начало последовательности заново: следующая проверка через сутки                        |
| Ответ раньше срока                                     | Не меняет расписание, статус и журнал                                                   |
| Повторная отправка одного ответа / устаревшая карточка | Не меняет расписание и журнал                                                           |
| Просрочка                                              | Интервал отсчитывается от фактического ответа, пропущенные дни не дают бонусных успехов |
| Ручная отметка «Выучил»                                | Самооценка, без выдуманных успешных проверок; первая проверка через сутки               |
| Возврат в «Учу» вручную                                | Сброс последовательности, самостоятельная проверка доступна сразу                       |

Три успешные проверки для нового значения проходят не раньше дней 0, 1 и 4. После третьей следующая назначается на день 11. Каждая ошибка требует новой последовательности.

«Пора повторить» — вычисляемое состояние, которое временно заменяет видимую отметку «Учу» или «Выучил», когда наступил срок. Это не автоматическое признание слова забытым. После ответа снова отображается базовое состояние с новым сроком. Время интерфейса обновляется на ближайшей границе, раз в минуту и при возвращении во вкладку.

Режим «Учу» содержит новые и наступившие изучаемые значения. «Повторяю» содержит все значения с наступившим сроком, включая изучаемые после ошибки. Будущие задания не выдаются для повторного набора успехов. Если время ещё не пришло, можно перейти к чтению.

## Самостоятельная проверка

- До ответа справка по карточке и глобальная кнопка `?` показывают только инструкцию, без целевого слова, перевода, синонимов, озвучки и ИИ-диалога.
- В карточке показываются образ и/или английский контекст выбранного значения. Целевое слово и явно заданные синонимы скрываются во всех вхождениях примера и определения. Английские варианты — само задание, а не отдельная подсказка.
- Для своих изображений выбирайте картинки без английских подписей: приложение не выполняет OCR и не удаляет текст.
- После ответа доступны все принятые варианты, перевод, полный пример, перевод примера, справка и следующий срок.
- Каждая попытка записывается одной операцией вместе с обновлением расписания. История и параметры сохраняются в резервной копии.

## Синонимы и неправильные ответы

В каждом задании четыре разных варианта: основное слово, максимум один явно заданный синоним и два или три неправильных ответа. Порядок перемешивается заново при новой выдаче задания и остаётся стабильным до ответа.

Отвлекающие варианты берутся из редакционных наборов по значению, затем из локального словаря с приоритетом части речи, темы и уровня, затем из явно заданного запаса для части речи. Не используются одинаковые нормализованные написания, заявленные синонимы и их обратные/транзитивные связи, одинаковые переводы и общие неоднозначные иллюстрации. Если безопасных вариантов не хватает, приложение предлагает исправить запись, а не выдаёт пустое или заведомо неправильное задание.

Синонимы действуют только для данной записи. Регистр, лишние пробелы и типографские апострофы не меняют правильность ответа. Автоматического определения всех синонимов или эквивалентности разных русских переводов нет. Для неизвестного значения часть речи нужно указать вручную перед зачётной практикой; она не угадывается по написанию или пробелам. Для точного совпадения с редакционным значением используется его сохранённая часть речи, в том числе для старых записей. Для своих слов можно добавить синонимы, пример и перевод примера. Их содержательную корректность проверяет автор записи.

`book — книга`, `book — бронировать`, `light — свет`, `light — лёгкий по весу`, `key — ключ`, `key — клавиша` представлены отдельными значениями. Материалы подставляются только при совпадении написания и значения. Изменение значения при редактировании сбрасывает прежнее подтверждение и очищает перенесённые из прежнего значения материалы, если человек не заменил их самостоятельно.

В чтении подсветка ищет написания, а не определяет смысл предложения. Если в словаре или редакционной подборке есть несколько значений, человек выбирает подходящее. Чтение, озвучка и справка не повышают уровень владения.

## Статистика и цель

Три видимых состояния не пересекаются; их количества в сумме дают размер коллекции. Отдельно показано, сколько базовых отметок «Выучил» подтверждено новой последовательностью интервальных проверок и сколько поставлено по самооценке/унаследовано без подтверждения.

Точность — доля правильных ответов среди всех самостоятельных ответов за последние 7 местных календарных дней, включая сегодня; при отсутствии ответов показано «—». Рядом указано число ответов. Будущие даты журнала исключаются из статистики до их наступления.

Дневная цель считает разные ID значений с самостоятельным ответом за местный календарный день. Правильный и ошибочный ответ считаются практикой; повтор одного значения в тот же день не увеличивает цель. По умолчанию — 10, можно выбрать другую цель или отключить её. Достижение цели не блокирует продолжение и не меняет расписание. Нет штрафа за пропущенный день, очков и требований поддерживать серию.

## Совместимость и ограничения

Старые резервные копии продолжают загружаться. Их сроки сохраняются, но прежний счётчик быстрых успехов без `lastReviewedAt` не считается доказательством трёх разнесённых проверок: новая последовательность начинается с первого зачётного ответа. Старые переводы не переписываются автоматически.

Обычный импорт списка добавляет значения и самооценку; успешные проверки и сроки из произвольной строки не создают историю обучения. Для точного переноса истории используйте полную резервную копию и действие «Восстановить весь прогресс»; оно сохраняет ID, журнал, расписание и ежедневную цель.

Встроены 10 000 словарных карточек и 28 редакционных значений, 5562 словарных сочетания и 12 редакционных выражений, 3 учебных текста. Словарные определения и русские соответствия связаны по WordNet synset ID. Для словарной карточки подходит английское определение со скрытым целевым словом и синонимами, без притворной картинки; неподтверждённый ID сам по себе не делает произвольный текст готовым заданием. Новая сессия ограничена 10 значениями. Темы словаря определены по категориям WordNet, порядок — по частоте написаний в субтитрах. Частота отдельных значений, CEFR и ваш уровень не оцениваются. Ошибки исходных соответствий возможны; база проверена алгоритмически, а не просмотрена поштучно человеком. Реальная генерация доступна только через отдельно подключаемый API и не участвует в оценке самостоятельного ответа.

«Выучил» означает выполнение правил распознавания в этом приложении, а не доказанную способность свободно употреблять слово или гарантию долгосрочного запоминания. Часы и сохранение зависят от устройства и браузера; синхронизации между устройствами нет.

Тесты правил: `tests/learning.test.ts`. Браузерный многодневный цикл, блокировка подсказок, разные значения, цель и автоматическое наступление срока: `tests/e2e/learning.spec.ts`. Фактические итоговые проверки — в [VALIDATION.md](VALIDATION.md).

Большие сохранения автоматически сжимаются без изменения содержимого. Полная резервная копия остаётся обычным JSON; изображения всё равно могут исчерпать квоту браузера. Встроенная большая база хранится отдельно от личного прогресса. Подробности источников и алгоритма: [WORD_BANK.md](WORD_BANK.md).
